# HDMS Staff PWA

Hito Device Management System — staff self-service progressive web application.

- Port: `5175`
- Supports staff sign-in via Microsoft Entra ID or employee number + password.
- Provides mobile view of borrower QR credentials, current device loans, and device catalogue.
- Staff can reserve devices from device details and cancel their own active reservations from Home. Admins configure the advance window, maximum duration, and the gap required after an expected return and between reservations under Settings → Policy (defaults: 90 days, 30 days, and 60 minutes).
